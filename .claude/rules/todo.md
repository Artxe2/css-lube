# TODO

A request with several tasks goes into the repository's `TODO.md` first, before the work starts, one plain list item a task (`- ...`, no checkbox). Each item is deleted as soon as its task is done, in the same commit as the work, so the file only ever lists what is left (an emptied section goes too). A task found on the way that the request needs becomes an item too.

Every request may start in a new session or after `/clear`, so nothing left open lives only in the final report: whatever a task leaves open goes into `TODO.md` in the task's commit, even when the report names it too (a decision put to the owner, a follow-up offered, a flaw or an unchecked case found on the way). A decision goes under `## Owner decisions` with its options and the recommendation, its work waiting for the answer (an answered one whose work is not done leaves a task behind); what only a person can do (a real account, another PC, the feel in play) goes under `## Owner checks`. Each item stands on its own for a session that never saw this one: what, the numbers, and where the known facts are (the file path and symbol, not a line number, which moves; the cause if it was found, or that it was not traced; the command that measures it). A request that does not say what it is about answers one of these items, so read `TODO.md` first.
